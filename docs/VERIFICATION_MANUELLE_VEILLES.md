# Vérification manuelle des veilles

La valeur manuelle est prioritaire dans l’interface et l’API; la valeur automatique reste conservée pour l’audit.

## Fiche

- Source :
- Source correcte (oui/non) :
- Titre affiché :
- Titre réel :
- Titre correct (oui/non) :
- Date affichée :
- Date réelle :
- Date correcte (oui/non) :
- Résumé fidèle (oui/non) :
- Pertinence pour ARMA (oui/non) :
- Catégorie :
- Destination :
- Lecture pour ARMA :
- Décision (garder/corriger/exclure/historique/transférer vers Réputation) :
- Notes :

L’utilisateur ouvre **Vérifier**, compare la source originale, corrige uniquement les champs nécessaires et s’identifie via `X-ARMA-User`. Une exclusion retire la veille du Marketing sans supprimer la donnée brute.
